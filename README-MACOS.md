# Discord Backup Bot для macOS

Программа сохраняет доступную структуру и историю сервера Discord в локальную папку `data` и восстанавливает их на другом сервере. Python устанавливать не нужно. Для копирования компьютер должен оставаться включённым и подключённым к интернету.

## Какой архив выбрать

Откройте меню Apple → **Об этом Mac**. Для процессоров Apple M1, M2, M3 и других Apple Silicon выберите архив `macOS-Apple-Silicon`; для процессора Intel — `macOS-Intel`. Сборки проверены на macOS 15; на других версиях macOS совместимость не гарантируется.

Распакуйте весь архив в отдельную постоянную папку с правом записи, например в «Документы». Рядом с программой должно хватать свободного места для файлов сервера. Не запускайте программу из окна просмотра архива.

В папке находятся исполняемый файл `DiscordBackupBot`, команды `1 - Edit Token.command`, `2 - Start Bot.command`, `3 - Check Backups.command`, шаблон `.env`, инструкция и лицензия. Папка `data` появится после запуска и будет содержать резервные копии и вложения.

Программа не подписана сертификатом Apple Developer и не нотариально заверена Apple: macOS может заблокировать первый запуск. Запускайте архив только если доверяете его источнику. При блокировке откройте «Системные настройки» → «Конфиденциальность и безопасность» и воспользуйтесь предложенным macOS способом разрешить открытие программы. Для выполнения `.command` может потребоваться разрешить запуск в настройках безопасности; при проблемах читайте сообщение macOS. Не меняйте глобальные настройки безопасности.

## Создайте и пригласите бота

1. Откройте [Discord Developer Portal](https://discord.com/developers/applications), войдите в аккаунт и создайте приложение через **New Application**.
2. В разделе **Bot** создайте или сбросьте токен. Токен даёт доступ к боту: не публикуйте и не отправляйте его другим людям.
3. В **Bot → Privileged Gateway Intents** включите **Message Content Intent** и сохраните изменения. Для некоторых приложений Discord может требовать отдельного одобрения.
4. В настройках установки приложения включите **Guild Install**, scopes `bot` и `applications.commands`, право **Administrator** и используйте ссылку установки, чтобы пригласить бота на исходный и целевой серверы.
5. На исходном сервере бот должен видеть нужные каналы и историю. На целевом сервере роль бота должна стоять выше ролей, которыми он управляет. Для некоторых типов каналов требуются функции Community.

## Настройте и включите

1. Дважды нажмите `1 - Edit Token.command`. В TextEdit откроется файл настроек.
2. Замените `вставьте_токен_бота` собственным токеном, сохранив строку `DISCORD_TOKEN=ваш_токен` без кавычек и лишних пробелов. Сохраните файл и закройте TextEdit.
3. Дважды нажмите `2 - Start Bot.command`. Откроется Terminal; дождитесь подключения бота к Discord и оставьте окно открытым.
4. Не запускайте второй экземпляр с той же папкой данных. Для остановки после завершения операций нажмите `Ctrl+C` в Terminal. Для нового запуска снова откройте `2 - Start Bot.command`.

## Копирование и восстановление

Команды вводятся **в Discord**, а не в Terminal. Каждую команду может вызвать только владелец текущего сервера. Для восстановления снимка тот же аккаунт должен владеть и исходным, и целевым сервером.

1. На исходном сервере введите `/backup`. Дождитесь окончания и запомните номер снимка.
2. Введите `/backup_info`, чтобы посмотреть свои последние снимки, либо задайте поле `backup_id` для подробностей. `complete` означает отсутствие обнаруженных ошибок чтения; `partial` — есть ошибки, изучите предупреждения; `failed` — ошибка; `running` — операция выполняется или была прервана.
3. На отдельном целевом сервере, где также установлен бот, вызовите `/restore` и укажите номер в поле `backup_id`. Необязательный `mode` выбирает отдельные или компактные сообщения.
4. Дождитесь завершения и вызовите `/restore_info` на целевом сервере. Сверьте сообщения, роли, каналы и предупреждения.

Бот создаёт новые роли и каналы и изменяет права `@everyone`; существующие каналы он не удаляет. Восстановление на исходный сервер запрещено. Повтор того же снимка на тот же сервер заблокирован до успешной тестовой очистки; другие снимки могут создавать дубликаты. Автоматического отката нет.

Если роль или участник из прав канала отсутствует, бот пропускает соответствующую запись прав, но создаёт канал и переносит доступную историю. **Доступ к каналу может отличаться от исходного**: для личной истории используйте закрытый архивный сервер и проверьте права вручную.

## Команды

| Команда | Действие |
| --- | --- |
| `/backup` | Создать снимок текущего сервера. |
| `/backup_info` | Показать свои снимки; параметр `backup_id` показывает детали. |
| `/restore` | Восстановить снимок с указанным `backup_id`; необязательный `mode`. |
| `/restore_info` | Показать историю восстановлений на текущем сервере. |
| `/wipe_test` | Сразу очистить подходящий тестовый сервер перед повторным восстановлением. |
| `/wipe_info` | Показать последнюю очистку текущего сервера. |

`/wipe_test` **необратимо удаляет** другие каналы вместе с сообщениями и обычные роли на текущем сервере. Текущий текстовый канал и его сообщения, `@everyone` и управляемые роли остаются. Команда доступна только на целевом сервере, где уже запускалось восстановление; сервер, для которого в базе есть снимок, защищён от очистки. После неполной очистки повторное восстановление заблокировано.

## Проверка и перенос данных

Остановите бота и запустите `3 - Check Backups.command`. Проверка читает базу, статусы и метаданные и проверяет наличие файлов. Она не подтверждает целостность содержимого вложений по контрольной сумме, полноту данных и успешность восстановления в Discord.

Чтобы перенести снимки, остановите бота и защищённым способом скопируйте всю папку `data` рядом с программой на другом компьютере. В ней могут быть личные сообщения и файлы. Не пересылайте свой `.env` с токеном или снимки посторонним.

## Ограничения и ошибки

Сообщения публикуются заново от имени бота с исходными автором и временем; исходные ID и время создания Discord сохранить нельзя. Ссылки в embeds и большие файлы могут не перенестись. Состав участников приватных веток, реакции, закрепления, назначения ролей, эмодзи, вебхуки, приглашения и некоторые настройки не копируются; сохраняются название стикера и ссылка, но не сам файл. Снимок не атомарный: изменения во время копирования могут попасть в него частично.

Если бот не запускается, проверьте архитектуру, настройки безопасности macOS и токен. Если команды не видны, убедитесь, что бот запущен и приглашён с `applications.commands`; глобальная регистрация может занять время. Если данных не хватает, проверьте Message Content Intent, права и предупреждения `/backup_info` и `/restore_info`. Если после остановки остался статус `running`, данные на сервере могут быть частично применены: сначала изучите сервер и сохраните копию `data`, не меняйте статусы вручную.
